QUICK START (5 MINUTES TO FIRST SCRAPE)
═══════════════════════════════════════════════════════════════════════

1. Extract the archive on your machine:
   
   cd /path/to/belief-transformer/V3/
   tar -xzf belief_ingest_complete.tar.gz
   cd belief_ingest

2. Run setup script:
   
   bash setup.sh
   
   This will:
   - Check Python version
   - Install all dependencies
   - Create directory structure
   - Run test suite
   - Ask about optional Playwright installation

3. Quick test (1 week):
   
   python scrape_12_months.py --start 2024-12-15 --end 2024-12-21
   
   Should complete in 5-10 minutes
   Output: ~50-100 articles in data/processed/

4. Production run (12 months):
   
   python scrape_12_months.py
   
   Expected: 4-8 hours, 20,000-40,000 articles

POST-PROCESSING
═══════════════════════════════════════════════════════════════════════

Merge Batch Files
  cat data/processed/batch_*.jsonl > articles_12mo.jsonl

Count Articles
  wc -l articles_12mo.jsonl

Top Publishers
  cat articles_12mo.jsonl | jq -r '.publisher' | \
      sort | uniq -c | sort -rn | head -20

Articles by Month
  cat articles_12mo.jsonl | jq -r '.published_at[:7]' | \
      sort | uniq -c

Average Sentiment by Publisher
  cat articles_12mo.jsonl | \
      jq -r '[.publisher, .sentiment_score] | @tsv' | \
      awk '{sum[$1]+=$2; count[$1]++} END {
          for (p in sum) print p, sum[p]/count[p]
      }' | sort -k2 -n


INTEGRATION WITH BELIEF TRANSFORMER V2

3. Compute θ fingerprints
   cd ../../V2

       --input data/raw/articles_12mo.jsonl \

   python -m belief_transformer.analyze_stances \
       --embeddings data/embeddings/ \
       --output results/

CHECKPOINTING SYSTEM
═══════════════════════════════════════════════════════════════════════

Automatic checkpoints after each batch enable:
- Resuming after interruptions (network, power, etc.)
- Pausing to free up resources
- Distributed processing (run batches on different machines)

Checkpoint file: data/cache/checkpoint.json

To resume:
  python scrape_12_months.py --resume

To start fresh (ignoring checkpoint):
  rm data/cache/checkpoint.json
  python scrape_12_months.py


TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

Common Issues:

1. Missing pandas
   Error: ModuleNotFoundError: No module named 'pandas'
   Fix:   pip install pandas --break-system-packages

2. High extraction failure rate (>30%)
   Check: cat articles.jsonl | jq '.extraction_method' | sort | uniq -c
   Fix:   Install playwright for JS-heavy sites
          pip install playwright --break-system-packages
          playwright install chromium

3. Memory issues
   Symptoms: Process killed, slow performance
   Fix:      Reduce batch size
             python scrape_12_months.py --batch-days 3

4. Network timeouts
   Symptoms: Many "fetch_failed" in logs
   Fix:      Increase timeout in config.py
             REQUEST_TIMEOUT = 60  # was 30

5. GDELT connection issues
   Test:  python -c "from gdelt_historical_fetcher import *; \
              import asyncio; asyncio.run(test())"
   Fix:   Check internet connection, retry later


PERFORMANCE OPTIMIZATION
═══════════════════════════════════════════════════════════════════════

Default settings are optimized for residential internet.

For faster scraping (server/datacenter):

Edit config.py:
  MAX_CONCURRENT_ARTICLES = 200    # was 100
  REQUEST_TIMEOUT = 15             # was 30
  BATCH_SIZE = 1000                # was 500

Run with smaller batches:
  python scrape_12_months.py --batch-days 3

For slower/unreliable connections:

Edit config.py:
  MAX_CONCURRENT_ARTICLES = 50     # was 100
  REQUEST_TIMEOUT = 60             # was 30
  RETRY_ATTEMPTS = 5               # was 3
