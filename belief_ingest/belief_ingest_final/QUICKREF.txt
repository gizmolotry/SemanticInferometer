SETUP (One Time)
════════════════════════════════════════════════════════════════════════
  bash setup.sh                    # Install dependencies & test


PRODUCTION COMMANDS
════════════════════════════════════════════════════════════════════════
  # Full 12-month scrape (default)
  python scrape_12_months.py

  # Custom date range
  python scrape_12_months.py --start 2024-01-01 --end 2024-12-31

  # Resume after interruption
  python scrape_12_months.py --resume


TEST COMMANDS (Recommended Before Full Scrape)
════════════════════════════════════════════════════════════════════════
  # Test suite
  python test.py

  # Quick 1-week test
  python scrape_12_months.py --start 2024-12-15 --end 2024-12-21

  # 1-day test
  python scrape_12_months.py --start 2024-12-20 --end 2024-12-21 --batch-days 1


POST-PROCESSING
════════════════════════════════════════════════════════════════════════
  # Merge batches into single file
  cat data/processed/batch_*.jsonl > articles_12mo.jsonl

  # Count articles
  wc -l articles_12mo.jsonl

  # Top publishers
  cat articles_12mo.jsonl | jq -r '.publisher' | sort | uniq -c | sort -rn | head -20

  # Articles by month
  cat articles_12mo.jsonl | jq -r '.published_at[:7]' | sort | uniq -c

  cd ../V2

      --input data/raw/articles_12mo.jsonl


COMMON ISSUES
════════════════════════════════════════════════════════════════════════
  Problem: "ModuleNotFoundError: No module named 'pandas'"
  Fix:     pip install pandas --break-system-packages

  Problem: High extraction failure rate
  Fix:     pip install playwright --break-system-packages
           playwright install chromium

  Problem: Memory issues
  Fix:     python scrape_12_months.py --batch-days 3

  Problem: Network timeouts
  Fix:     Edit config.py: REQUEST_TIMEOUT = 60


MONITORING PROGRESS
════════════════════════════════════════════════════════════════════════
  The scraper logs progress after each batch:
  
  - Batches complete / total
  - Articles fetched / extracted / failed
  - Percent complete
  - Estimated time remaining

  Progress is saved to checkpoint.json after each batch.
  Safe to interrupt with Ctrl+C - resume with --resume flag.
