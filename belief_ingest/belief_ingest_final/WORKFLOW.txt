                                                    ↓

  - Memory efficient (process 7 days at a time)
  - Resumable (checkpoint after each batch)
  - Progress tracking (see completion %)

TROUBLESHOOTING DECISION TREE
═══════════════════════════════════════════════════════════════════════════

  Scraper fails?
    │
    ├─ Missing pandas? ────────→ pip install pandas --break-system-packages
    │
    ├─ Network timeout? ───────→ Edit config.py: REQUEST_TIMEOUT = 60
    │
    ├─ High failure rate? ─────→ pip install playwright --break-system-packages
    │                             playwright install chromium
    │
    ├─ Memory issues? ─────────→ python scrape_12_months.py --batch-days 3
    │
    └─ Other errors? ──────────→ python test.py
                                  Check logs/scraper.log
